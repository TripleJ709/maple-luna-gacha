# 루나쁘띠 뽑기 시뮬레이터

메이플스토리의 **위습의 원더베리 → 루나 크리스탈 스윗 → 루나 크리스탈 드림** 흐름을 체험해 보는 웹 시뮬레이터입니다.

> **비공식 팬 프로젝트**입니다. 넥슨 및 메이플스토리와 관련이 없습니다.
> **실제 결제는 이루어지지 않습니다.** 캐시 충전과 구매는 모두 가상입니다.

## 사용 방법

1. 캐시를 충전합니다. (10,000원 ~ 1,000,000원, 현재 캐시에 더하기만 합니다)
2. 캐시샵에서 원더베리와 루나 크리스탈을 구매합니다.
   - 원더베리 1개 5,400원 / 11개 54,000원
   - 루나 크리스탈 1개 3,900원
3. 원더베리로 1회 또는 5회 뽑기를 합니다. (희귀 아이템이 원더 블랙 펫입니다)
4. **스윗 합성:** 원더 블랙 펫 2개(종류 무관) + 루나 크리스탈 1개
5. **드림 합성:** 루나 스윗 펫 1개 + 원더 블랙 펫 1개 + 루나 크리스탈 1개 (드림 펫은 재료로 쓸 수 없습니다)

누적 사용 금액은 구매에 쓴 금액의 합계입니다. 데이터는 브라우저의 `localStorage`에 저장됩니다. (브라우저 데이터를 지우면 초기화됩니다)

## 확률 출처 (메이플스토리 공식 홈페이지)

- [위습의 원더베리](https://maplestory.nexon.com/Guide/CashShop/Probability/WispsWonderBerry) (2026-09-24 오전 10시 이후 확률 적용)
- [루나 크리스탈 스윗](https://maplestory.nexon.com/Guide/CashShop/Probability/LunaCrystalSweet)
- [루나 크리스탈 드림](https://maplestory.nexon.com/Guide/CashShop/Probability/LunaCrystalDream)

드림 합성에서 재료로 쓴 스윗 펫과 같은 종류의 드림 펫은 제외하고, 공식 안내의 계산식대로 나머지 확률을 균등 배분합니다.

## 개발

HTML, CSS, JavaScript만 사용하며 빌드 과정이 없습니다. `index.html`을 브라우저에서 열면 실행됩니다.

```
node --test "tests/*.test.js"   # 확률/상태 로직 테스트 (Node 18 이상)
```

- `js/data.js`: 확률표, 가격, 아이템 이름과 이미지 경로
- `js/gacha.js`: 추첨 로직
- `js/state.js`: 상태, 충전/구매/뽑기/합성 규칙, 저장
- `js/ui.js`: 화면 연결

아이템 이미지를 쓰려면 `assets/`에 파일을 넣고 `js/data.js`의 `image` 필드에 경로를 적습니다. 게임 이미지는 넥슨의 저작물이므로 이용 가이드라인을 확인한 뒤 사용하세요.
