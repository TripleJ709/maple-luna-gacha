# 루나쁘띠 뽑기 시뮬레이터 - 작업 목록

메이플스토리 위습의 원더베리 / 루나 크리스탈 스윗 / 드림 흐름을 HTML, CSS, JavaScript만으로 재현하는 정적 웹 시뮬레이터. GitHub Pages로 배포한다. 실제 결제는 없다.

## 확정 사항

- 기술: HTML/CSS/JS only. 테스트는 Node 내장 `node --test` (개발용).
- 확률 출처(공식, 2026-09-24 오전 10시 이후 표):
  - https://maplestory.nexon.com/Guide/CashShop/Probability/WispsWonderBerry
  - https://maplestory.nexon.com/Guide/CashShop/Probability/LunaCrystalSweet
  - https://maplestory.nexon.com/Guide/CashShop/Probability/LunaCrystalDream
- 충전 10,000~1,000,000원(단순 가산). 누적 사용 금액 = 구매에 쓴 금액 합(충전 제외).
- 가격: 원더베리 1개 5,400원 / 11개 54,000원, 루나 크리스탈 1개 3,900원.
- 뽑기 1회 = 원더베리 1개, 5회 = 5개.
- 스윗: 원더 블랙(희귀) 2개(종류 무관) + 크리스탈 1개.
- 드림: 스윗 펫 1 + 원더 블랙 1 + 크리스탈 1. 스윗 펫이 베이스(같은 종류 제외, 나머지 8종 각 9.45%). 드림 펫은 재료 불가.
- 이미지 없이 텍스트/이모지/CSS. 이름과 이미지 경로는 `js/data.js` 한 곳에 모은다.
- 커밋당 200~400줄 이내. 커밋/푸시는 사용자 확인 후.

## 2차 개선 (Task 8 이후)

원칙: 모든 상태는 `createState()` 한 곳에서 정의한다. (초기화 버튼이 새 상태 필드를 자동으로 포함하도록)

- [x] **A: 레이아웃 3분류** - 탭 3개(캐시/캐시샵, 원더베리 뽑기, 스윗/드림 합성), 상단 재화 표시줄, 인벤토리 상시 표시
- [x] **B: 결과 확인 후 인벤토리 반영** - 뽑기/합성 결과는 "대기(pending)" 상태로 저장하고, 확인을 눌러야 인벤토리에 반영. 새로고침 시 팝업 재표시, Esc로 닫으면 확인 처리
- [x] **C: 통계와 기록** - 횟수, 결과별 횟수, 실제 확률 vs 공식 확률, 최근 내역
- [x] **D: 자동 반복 합성** - 원하는 결과가 나올 때까지 반복, 총 사용 금액 계산
- [x] **E: 초기화 버튼** - 확인 창 후 캐시/인벤토리/통계/기록 전체 초기화 (C, D 이후)
- [x] **F: 이미지 추가 적용** - 스윗/드림 펫 9종, 루나 크리스탈 키. 사용자가 다운로드 폴더에 이미지를 두면 `IMAGES`에 연결
  - 1차 적용: 정지 이미지 13종, 펫 영상(mp4 16종, gif 1종), 원더베리 아이콘(webp). 루나 크리스탈 키만 이미지 없음
- [x] **G: 희귀 획득 연출** - 원더 블랙/루나 쁘띠 획득 시 금빛 팝업, 회전 빛줄기, 반짝이, 화면 흔들림, 희귀 카드 마지막 등장 (동작 줄이기 설정 시 애니메이션 끔)
- [x] **H: 합성 방식 변경** - 버튼 하나("루나 크리스탈 사용하기")로 스윗/드림 통합. 보유한 원더 블랙·루나 스윗 펫만 표시, 조합 불가 재료는 회색 처리, 먼저 넣은 재료에 따라 가능한 합성과 쁘띠 확률 안내. 루나 크리스탈 이미지 적용
